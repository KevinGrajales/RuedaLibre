La organización de los archivos de Rueda Libre permite separar la estructura, la presentación y el comportamiento del sitio web.

HTML organiza el contenido, CSS define su apariencia y JavaScript puede utilizarse para incorporar funcionalidades interactivas.

Recurso de destino: CSS/styles.css
Ruta relativa: CSS/styles.css
Descripción: Permite conectar la página principal con la hoja de estilos.

Recurso de origen: Paginas/tarifas.html
Recurso de destino: CSS/styles.css
Ruta relativa: ../CSS/styles.css
Descripción: Permite conectar la página de tarifas con la hoja de estilos ubicada en la carpeta principal.

Recurso de origen: Paginas/reservas.html
Recurso de destino: CSS/styles.css
Ruta relativa: ../CSS/styles.css
Descripción: Permite conectar la página de reservas con la hoja de estilos ubicada en la carpeta principal.

Recurso de origen: index.html
Recurso de destino: Paginas/tarifas.html
Ruta relativa: Paginas/tarifas.html
Descripción: Permite navegar desde la página principal hasta la página de tarifas.

Recurso de origen: index.html
Recurso de destino: Paginas/reservas.html
Ruta relativa: Paginas/reservas.html
Descripción: Permite navegar desde la página principal hasta la página de reservas.

Recurso de origen: Paginas/tarifas.html
Recurso de destino: Paginas/reservas.html
Ruta relativa: reservas.html
Descripción: Permite navegar desde la página de tarifas hasta la página de reservas, siempre que ambas páginas estén dentro de la carpeta Paginas.

Recurso de origen: Paginas/reservas.html
Recurso de destino: Paginas/tarifas.html
Ruta relativa: tarifas.html
Descripción: Permite navegar desde la página de reservas hasta la página de tarifas, siempre que ambas páginas estén dentro de la carpeta Paginas.
