* FORMULARIO DE RESERVA — reservas.html

* Se creó una sección denominada "Formulario de reserva" dentro del contenido principal de la página.

* El formulario utiliza el método POST para enviar los datos y está organizado en tres grupos mediante las etiquetas FIELDSET y LEGEND:

    * Tus datos: contiene el nombre completo, el correo electrónico y el teléfono del cliente.
    * Tu alquiler: contiene el tipo de bicicleta, la fecha de reserva y la duración del alquiler.
    * Confirmación: contiene el medio de contacto preferido, las observaciones adicionales y una casilla de confirmación de los datos.

* JUSTIFICACIÓN DE LOS CONTROLES:

    1. Correo electrónico (input type="email"): se eligió porque permite introducir una dirección de correo y proporciona una validación básica de su formato.

    2. Tipo de bicicleta (select): se eligió porque el cliente debe seleccionar una bicicleta entre varias opciones predefinidas, lo que facilita la selección y evita respuestas arbitrarias.

    3. Medio de contacto (input type="radio"): se eligió porque el cliente debe seleccionar una sola alternativa entre las opciones disponibles.

* ASOCIACIÓN DE ETIQUETAS Y CONTROLES:

    Cada control tiene una etiqueta visible mediante LABEL. El atributo FOR de cada etiqueta coincide con el ID del control correspondiente, de modo que al hacer clic en la etiqueta se activa el campo asociado.

* ENVÍO DEL FORMULARIO:

    Se asignó un atributo NAME a cada control que debe enviar datos. El formulario utiliza METHOD="post" y contiene un botón final de tipo SUBMIT denominado "Enviar reserva".

* PRUEBAS:

    Se verificó que las etiquetas activaran sus campos correspondientes y que los controles fueran utilizables. El formulario es una demostración de HTML y no procesa ni almacena reservas en un servidor.

PROYECTO: RUEDA LIBRE

* 1. AUDITORÍA DE ACCESIBILIDAD

Se revisaron las páginas index.html, Paginas/tarifas.html y Paginas/reservas.html.

Aspectos evaluados:

- Textos alternativos de las imágenes.
- Jerarquía de encabezados.
- Claridad de los textos de los enlaces.
- Idioma declarado en el documento.
- Recorrido completo mediante teclado.

Correcciones previstas o realizadas:

- Las imágenes informativas deben tener textos alternativos descriptivos.
- Las imágenes decorativas deben utilizar alt="".
- Los encabezados deben seguir una jerarquía lógica, utilizando h1 para el título principal, h2 para las secciones y h3 para los artículos cuando corresponda.
- Los enlaces deben tener textos que permitan comprender su propósito.
- Los tres documentos deben declarar el idioma español mediante lang="es".
- Se debe comprobar que los enlaces y controles sean accesibles mediante Tab, Shift + Tab, Enter, las flechas y la barra espaciadora cuando corresponda.
- Se debe comprobar que el indicador de foco del teclado sea claramente visible.

* 2. AUDITORÍA DE CONTRASTE

Se evaluaron las ocho combinaciones de colores propuestas por el cliente.

Criterios utilizados:

- Apto para texto normal: contraste igual o superior a 4.5:1.
- Apto solo para texto grande: contraste igual o superior a 3:1 e inferior a 4.5:1.
- No apto: contraste inferior a 3:1.

Resultados:

| Combinación | Contraste | Clasificación |
| Blanco sobre Verde Ruta | 5.31:1 | Apto para texto normal |
| Blanco sobre Naranja Pedal | 2.22:1 | No apto |

| Azul Noche sobre Crema | 14.83:1 | Apto para texto normal |
